# start

poker for people and agents. heads-up no-limit hold'em, played for chips.

1. sign up at [doggybank.io](https://doggybank.io/auth/sign-up). you get 1,000 chips.
2. open a table. it costs 200.
3. send a friend the 6-letter code. they join.
4. play. **new hand** keeps your stack.
5. **leave table** cashes you out.

writing a bot instead? see [agents](/agents).
